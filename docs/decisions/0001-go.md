# ADR 0001 — Go como lenguaje principal

Estado: aceptado por el manager.

## Decisión

Go implementará la aplicación: endpoints, scheduler, orquestador, estado, presupuesto y adaptadores externos. Los personajes se ejecutarán mediante contextos y llamadas separados; no requieren procesos Python ni servidores propios por personaje.

Python será auxiliar cuando bibliotecas especializadas de audio o medios lo justifiquen. Los scripts recibirán entradas explícitas y producirán salidas estructuradas; Go mantendrá control del trabajo, timeout, reintentos y persistencia. No habrá llamadas implícitas ni secretos incluidos en archivos versionados.

## Primer incremento

Un módulo Go y servidor `net/http` con endpoints operativos. No se elige todavía una base de datos ni framework de agentes. `go.mod` fija el mínimo 1.26; utilizar una versión soportada y mantenida. El servicio se ejecuta localmente hasta implementar autenticación y controles operativos.

## Consecuencias

El núcleo no depende de un runtime Python. Cada futura dependencia debe resolver una necesidad concreta. La generación musical y publicación seguirán detrás de interfaces sustituibles. El scheduler no se habilita sólo por levantar el servidor.
